# Comply.dev
Lightweight GRC automation & cloud risk insights platform
Comply.dev scans your AWS environment and GitHub repos for compliance gaps across common frameworks (SOC 2, ISO 27001, CIS Benchmarks). It automates control checks that auditors typically perform manually — encryption-at-rest validation, backup schedule verification, security group rule analysis, and IAM policy reviews — then generates a real-time compliance dashboard with remediation guidance.
Built by an auditor, for auditors.
